## 待开发功能 ❌

### P0 — 高优先级（搜索引擎 + 用户互动）

#### 1. robots.txt
- **目的**：搜索引擎爬虫配置，百度/Google 收录必需
- **位置**：`docs/site/robots.txt`（构建输出根目录）
- **内容**：
  ```
  User-agent: *
  Allow: /
  Sitemap: https://www.aipaikj.top/sitemap.xml
  ```
- **实现方式**：在 `docs/content/` 根目录创建 `robots.txt`，或通过 zensical.toml 配置
- **工作量**：小

#### 2. 评论区（Giscus）
- **目的**：每页底部评论互动，社区建设
- **方案**：Giscus（基于 GitHub Discussions）或 Utterances（基于 GitHub Issues）
- **位置**：`docs/overrides/partials/comments.html`
- **配置**：
  - Giscus：需要开启 GitHub Discussions
  - 仓库：1Cyrvox/ShuJing
  - 分类：Comments
  - 主题：跟随站点暗色/亮色
- **工作量**：中

#### 3. 中文 FAQ 页面
- **目的**：常见问题解答，降低用户支持成本
- **位置**：`docs/content/faq.md` 或 `docs/content/faq/index.md`
- **内容**：
  - 安装问题（pip install、引擎编译、依赖）
  - 使用问题（场景编写、渲染输出、中文支持）
  - 兼容性问题（Manim CE 迁移、API 差异）
  - 性能问题（渲染速度、内存优化）
- **导航**：在 `.nav.yml` 中添加"常见问题"入口
- **工作量**：中

### P1 — 中优先级（社区 + 分析）

#### 4. QQ群/微信群入口
- **目的**：中文社区入口，用户交流
- **位置**：页脚 `docs/overrides/partials/academa.html`
- **内容**：
  - QQ群号码 + 加群链接
  - 微信群二维码图片
  - GitHub Discussions 链接
- **工作量**：小

#### 5. 百度统计
- **目的**：用户行为分析，了解访问数据
- **方案**：百度统计 JS SDK
- **位置**：`docs/overrides/main.html` 的 `<head>` 中
- **配置**：
  ```html
  <script>
    var _hmt = _hmt || [];
    (function() {
      var hm = document.createElement("script");
      hm.src = "https://hm.baidu.com/hm.js?XXXXXXXX";
      var s = document.getElementsByTagName("script")[0];
      s.parentNode.insertBefore(hm, s);
    })();
  </script>
  ```
- **前置条件**：在百度统计注册站点获取代码
- **工作量**：小

#### 6. 微博/微信分享按钮
- **目的**：社交传播，扩大影响力
- **位置**：每页右侧浮动分享栏，或页脚分享按钮
- **方案**：
  - 微博分享：`https://service.weibo.com/share/share.php`
  - 微信分享：生成二维码图片
  - 复制链接按钮
- **工作量**：中

### P2 — 低优先级（内容 + SEO）

#### 7. 贡献者页面
- **目的**：展示项目贡献者，社区认同感
- **位置**：`docs/content/contributors.md`
- **方案**：
  - 通过 GitHub API 获取贡献者列表
  - 或手动维护贡献者信息
- **工作量**：小

#### 8. 项目路线图（Roadmap）
- **目的**：展示项目发展方向，吸引贡献
- **位置**：`docs/content/roadmap.md`
- **内容**：
  - 已完成功能
  - 进行中功能
  - 计划中功能
  - 长期目标
- **工作量**：小

#### 9. 百度SEO收录
- **目的**：百度搜索引擎收录
- **前置条件**：robots.txt 完成
- **步骤**：
  1. 百度搜索资源平台添加站点
  2. 验证站点所有权
  3. 提交 sitemap.xml
  4. 优化 meta 标签（title、description、keywords）
- **工作量**：小（但需要手动操作百度平台）

## 开发顺序

```
第一阶段：robots.txt → FAQ 页面 → 评论区
第二阶段：QQ群/微信群入口 → 百度统计
第三阶段：分享按钮 → 贡献者页面 → 路线图
第四阶段：百度SEO收录
```
