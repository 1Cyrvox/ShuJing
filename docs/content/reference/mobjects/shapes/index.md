# 形状

形状是一条路径：由描边绘制的曲线和由填充填充的区域（参见 [Paths](../paths.md)）。每种形状都是一个类：用其尺寸创建一个，然后像任何 mobject 一样放置和设置样式。

<div class="grid cards mx-cards" markdown>

-   ![](film:LinesAndArrows)

    [**线与箭头**](lines-and-arrows.md)

    ---

    点之间的线、指示方向的箭头、向量，以及终止它们的箭头尖端。

-   ![](film:CirclesAndArcs)

    [**圆与弧**](circles-and-arcs.md)

    ---

    圆、点、椭圆和弧，以及由它们制成的圆环和扇形。

-   ![](film:PolygonsHero)

    [**多边形**](polygons.md)

    ---

    由直边构成的形状，从三角形到星形，以及框住屏幕的矩形。

-   ![](film:CombiningShapes)

    [**组合形状**](combining-shapes.md)

    ---

    一个形状与另一个形状的并集、交集或差集、孔洞，以及凸包。

</div>
