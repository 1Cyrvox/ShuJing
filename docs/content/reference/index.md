# 参考

一段视频就是一个 **场景**。它在画面中显示 **mobject**：图形、文本、公式、图表
和曲面。**动画** 随时间改变它们，**更新器** 在每一帧保持一条规则。**相机** 决定
画面显示什么，平面或 3D。**声音** 和 **语音** 一同播放。**渲染** 生成视频。

本参考按此顺序讲述每个部分，以及它所能做的一切：[学习](../user-guide/the-basics.md)
讲述同一个故事，一次一个概念。
