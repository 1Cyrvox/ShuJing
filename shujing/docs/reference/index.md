# 参考

一段视频就是一个 **场景**（scene）。它在自己的画面中展示 **mobject**：形状、文字、公式、图形
和曲面。**动画**（animation）随时间改变它们，**更新器**（updater）在每一帧保持一条规则。
**相机**（camera）决定画面显示什么，是平面的还是三维的。**声音**（sound）和 **语音**（voice）
随之播放。**渲染**（rendering）生成视频。

本参考按此顺序讲述每个部分及其全部能力：[入门指南](../user-guide/the-basics.md)
以同样的脉络教学，一次讲一个概念。
